# Vaga-Alvo — AI Engineer

## Título

AI Engineer

## Resumo da Vaga

Profissional responsável por projetar, desenvolver e integrar soluções baseadas em Inteligência Artificial, incluindo aplicações com Large Language Models, RAG, agentes, APIs e serviços em nuvem.

## Responsabilidades

- Desenvolver aplicações com Large Language Models
- Construir pipelines de RAG
- Integrar modelos de IA com APIs e sistemas externos
- Criar e utilizar agentes de IA
- Desenvolver ferramentas e integrações para agentes
- Trabalhar com embeddings e busca vetorial
- Avaliar qualidade, relevância e groundedness das respostas
- Criar testes para aplicações de IA
- Desenvolver soluções utilizando Python
- Integrar aplicações com serviços de nuvem
- Utilizar Git e GitHub no ciclo de desenvolvimento
